# 点灯的曾曾 · 自媒体工作台试用版

新手请先阅读 [完整操作手册](点灯自媒体工作台-操作手册.md)，本页保留能力边界、上游来源与隔离验收记录。

## 使用入口

统一地址：http://127.0.0.1:8080 。灵感熔炉已改名为「点灯自媒体工作台」，个人创作能力融入同一导航；旧 `/workbench.html` 自动跳转。不再提供独立创作台登录。已有本机账户直接登录，新安装才初始化账户。

账号定位：产品视角的 AI 实测与方法分享。三个平台初始合计 50 粉丝，90 天净增 20,000 是实验目标，不是工具效果承诺。每周基础投入 18 小时，另留 0～4 小时缓冲。建议起步节奏：2 个选题、2 组图文、1 条录屏跨平台、1 篇公众号，再登记与复盘。

## 首次试用

1. 已有账户直接登录；只有全新安装才初始化账户。点击“载入示例”认路，示例不能原样发布。
2. 公众号页点击“排版预览”，检查正文、复制排版，粘贴到公众号后台再核对。
3. 图文页点击“导出卡片”，等待生成记录完成，下载每页 PNG。
4. 图片页选择画幅、色调和风格，点击“填入提示词”，修改后点击“Codex 生图”。
5. 素材页换成一次真实实测，生成候选稿，查看后点击“采用稿件”，再自行审校。
6. 视频页生成录屏脚本；在外部录制、剪辑后导入 MP4 成片。
7. 手动发布到三个平台，在复盘页登记作品链接、发布时间和表现，记录下一篇的单一改动。

## Obsidian 接入

点击“连接知识库”，选择库路径、接入目录和归档目录，再打开项目的“知识库”页。预览笔记后选为素材，生成时使用选择的文字；源文件变化会提示刷新。点击“归档到 OB”保存三端稿件、来源、复盘、图片与成片，OB 内修改的稿件可导入为候选稿，核对后采用。

接入不会移动旧笔记或安装插件；每次归档建立独立快照，不覆盖已有修改。Wiki 图片和 Markdown 本地图片支持导入，暂不自动展开嵌入笔记、PDF 和查询。详见 [调研、接入范围与验收](Obsidian接入与插件调研-2026-10-08.md)。

## Codex 运行方式

工作台调用本机 Codex CLI 的 ChatGPT 登录态；文字任务为只读沙箱，生图为任务目录写入沙箱，启用内置 image_generation。生成会使用账号的 Codex 配额。用户素材及必要参考会发送给模型，请勿填入客户机密或未授权资料。CLI 缺失、登录过期、额度不足、工具不可用都会报失败；没有返回 PNG 时不会伪装成功。

不加载用户自定义 CLI 配置；对子进程仅传启动、登录路径及网络必需环境，不传工作台 API 密钥。CLI 的生图事件可能不单独出现在 JSONL 中，因此按本次线程原生生成目录核验新鲜原图，并与任务图片比对 SHA-256；不能拿历史图或绘图脚本文件冒充成功。

`.env` 中可配置 `CODEX_BIN`。本机当前已用原生工具产出 PNG，但实际耗时与可用性仍取决于服务和账号。没有通过外部 API 假装使用 Codex 生图，也没有用 HTML 卡片替代 AI 图片。图文卡片是另一项明确标注的模板导出能力。

## 当前边界

- 不自动发布，不抓取粉丝数据，不保证涨粉；平台数据由本人登记。
- 不自动录制、剪辑、转写或烧录字幕；第一版完成脚本与成片交接。
- 图片导入最大 1 MB，MP4 最大 100 MB；原生生图与导出卡片无 1 MB 导入限制。
- 公众号校验确认结构与样式规则，不等于真实后台最终展示已经验证；图片仍需在后台上传，链接可能受公众号规则限制。
- 卡片会拒绝标题／正文过长或溢出的页面，不删内容、不自动缩到不可读字号。
- 仅监听 127.0.0.1，关闭旧系统外部采集定时任务；暂不作为多人或公网平台使用。
- 原系统的数据库备份不包含新工作台的图片和视频文件。迁移或完整备份时须另保留 `data/workbench/`，不能只复制数据库。
