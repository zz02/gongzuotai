## 2. 设计判断与验收清单

- 用户与任务：自媒体新手，为 AI 职场小白制作公众号、小红书及抖音图文；打开后能知道当前作品和下一步。
- 视觉方向：安静的创作编辑室。深绿用于导航与主动作，暖白用于正文，浅绿用于选择和进度；个人壁纸留在工作区外缘，不压在正文上。
- 记忆点：左侧“点”字标记、连续五步进度、平台独立状态与阅读预览；不使用虚构增长曲线和装饰性统计。
- 模板选择：本地 PUI 列表模板用于信源、选题与作品；编辑／详情模板用于稿件与图片；审批结构用于成品检查；配置模板用于外观。母版随原型携带，未引入第二套框架。
- 验收：菜单始终在左侧；页面主次明确；作品与平台稿不分叉；改稿不冒充旧成品；弹层可关闭并恢复焦点；三屏无页面横向溢出且分栏真实呈现；边界提示清楚；文档、页面、测试口径一致。

## 3. 页面交互与视觉口径

| 页面 | 布局与任务 | 主操作与闭环 |
|---|---|---|
| 信源 | 资讯流与创作定位并列，保留三个主信源分组 | 转为选题；重复来源返回已有选题 |
| 选题库 | 展示读者问题、角度和当前立项状态 | 开始创作；选择平台后只建作品，不自动生成 |
| 我的作品 | 列表展示各平台进度，继续当前作品 | 返回上次制作步骤，不复制出第二份稿 |
| 生成稿件 | 桌面左编辑、右阅读预览；手机切换编辑与预览 | 生成、检查、修改、确认；失败只重试对应平台 |
| 图片排版 | 桌面页面列表／画布／当前页设置三栏 | 每页确认模板；改稿后旧图待更新，确认文字前不能确认模板 |
| 发布成品 | 检查清单与发布记录并列 | 成品确认后下载成为主动作；登记保留快照，后续修订明确提示 |
| Skill 中心 | 能力分工说明，不代替新手创作入口 | 返回当前作品；原型不执行或更新能力 |
| 外观设置 | 上传、位置、遮罩、启用与恢复默认 | 本地保存；恢复外观不删除作品 |
| RedFox 原工具 | 仅说明正式原功能保护范围 | 不在原型中复刻、重设计或调用原工具 |

导航尺寸：桌面 232 像素；平板 72 像素图标栏；手机 56 像素图标栏。窄屏可展开 264 像素左侧文字菜单，保留可点击遮罩。不是顶部导航。

字体采用系统中文字体，正文 16 像素、辅助说明 12～14 像素、页面标题 24～28 像素；常用操作高度至少 44 像素。主色、文字、背景、边框和间距集中在项目主题中，组件状态沿用 PUI。图片画布是版式示意，不是最终品牌配图质量样稿。

## 6. 设计审查与剩余风险

人工启发式评价：设计 C → B，模板化观感 C → B；不是用户满意度数据或第三方认证。分项为：层级 B、字体 B、间距布局 B、颜色对比 B、交互状态 A、响应布局 B、内容品质 C、模板化观感 B、动效 B、性能感受 B。内容品质仍为 C，因为只有模拟文章与基础版式，没有真实配图与平台发布结果。

流程体验启发式为 70 → 85：入口与下一步清楚、边界明确、失败可恢复；剩余负担是逐页确认、平板预览在编辑区下方和长页滚动。以上只是设计判断，不是测量。

独立原生设计复核完成，指出弹窗背景、当前页语义、成品主按钮和重复样式问题，均已处理。外部跨模型审查不可用；不把本地独立复核声称为跨模型通过。可选视觉检测器未安装，未提供检测计数。没有新增工具或改项目规则。
