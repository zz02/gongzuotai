# 点灯自媒体工作台：统一创作交互原型

更新日期：2026-10-15。当前依据：[功能归属与关键交互](../../功能归属与关键交互-点灯工作台-2026-10-13.md)。以下「当前版本」为有效说明；文末旧版记录仅供追溯。

## 当前版本

打开 [交互原型](http://127.0.0.1:8098/index.html#content)，无需登录。需运行本机静态预览服务；也可直接打开本目录 `index.html`。所有素材、任务与发布记录都是模拟，不读正式数据、不请求外部服务、不写真实 OB。

### 这次改了什么

- 左栏只有内容创作、信源、知识库三个工作入口；Skills 中心、助手和设置为辅助入口。
- 内容支持从空白、选题、外部材料、OB 笔记和已有文章开始。可以加入已有内容，无需先过选题库。
- 同一编辑器内切换平台与正文、配图、成品、发布记录；稿件和平台互不覆盖。
- Skills 中心列出 16 项登记能力和 13 项待接入方法，支持任务筛选、作者搜索、详情和常用；待接入项没有假执行按钮。
- 从编辑器选方法直接使用当前稿；从中心使用方法需先选择目标。模拟结果在当前内容内采用、放弃或下载；保存建议后可在创作笔记查看。
- 原 RedFox 热榜、搜索、追踪、详情、收藏、原创作与设置演示继续可达，转入动作统一为「用于创作」。原工具仍有兼容页，尚未完成逐控件内嵌。
- 旧版演示存档读取为新版本副本；原存档不覆盖。旧 `flow.js` 保留追溯，但当前入口不加载它。

### 建议按这三条路径试用

**新增完整案例：从一条信源，到下一篇更懂你的稿。**

1. 信源 → AIHOT（也可 RedFox / 乔木 RSS）→ 收藏 OB。填写收藏理由，确认后看到模拟笔记；不会写真实知识库。
2. 在笔记详情点“用于创作”，新建公众号内容；可展开补充读者问题、内容角度和待补证据。
3. 编辑器展开参考材料 → 添加材料 → 引用一篇 OB 笔记；点写作方法 → 公众号写作 → 确认模拟 → 采用结果。
4. 亲手修改正文 → 复盘修改。查看差异，选择表达偏好，填写原因和规则，范围选公众号，勾选确认后保存经验。
5. 知识库 → 我的文风，可查看依据、停用；经验笔记与外部收藏分开。
6. 新建另一篇公众号内容，选择写作方法。生成前会出现刚才确认的偏好，可单次取消；模拟候选保留本次选用记录。
7. 回到第一篇制作配图、确认成品、下载预览，人工发布后模拟登记与归档；归档稿在知识库“成品归档”筛选下可查。

模拟只验证上下文传递和确认交互，不会真的训练模型，也不能用示例文案判断实际文风改善效果。

1. **知识库 → 勾选笔记 → 引用所选 → 新建内容 → 写作方法**：确认模拟后，候选在正文上方显示，点击采用才写入。
2. **信源 → RedFox → 作品详情 → 用于创作 → 加入已有**：引用增加，正文不变；原搜索与追踪仍在信源内。
3. **Skills 中心 → 搜索 db 或花叔 → 查看详情**：查看输入、产出与状态；已登记方法可模拟，花叔等待接入方法只展示规划。

成品试用：填标题、摘要／配文、正文 → 配图添加图页 → 模板预览 → 成品本人核对 → 确认成品 → 下载预览或模拟登记。生成和保存失败都有保护；模拟图卡带占位标识，不能冒称真实生成图片。

### 尚未完成的部分

- 本轮没有接真实模型、信源、发布或 OB；输出仅为示例 HTML，不是完整 PNG 成品包。
- 助手对话、完整 Skills 安装更新与绑定、知识连接管理、账号风格、视频和原概览仍是保留范围说明或兼容入口，没有全部做成交互演示。
- 五套既有主题与上传壁纸保留；内置壁纸图库及正式视觉美化在交互确认后进行。
- 尚未做正式数据迁移；自动保存只针对本浏览器的演示数据，容量不足时提示备份。

### 验证与评审

当前验收脚本：`verify-unified.cjs`；完整收藏与改稿学习场景：`verify-learning.cjs`。原 RedFox 回归脚本：`verify-redfox-recovery.cjs`。其他旧测试是历史导航与布局基线，不能当作当前版本全量通过证明。

详见 [本轮交互验收](../../交互原型验收-统一创作-2026-10-13.md)。本轮未声称完成 UI 美化，也不证明正式系统可用。

## 页面设计

默认深绿左侧导航、暖白创作区和统一控件。菜单分为创作工作区、创作辅助、RedFox 工具区；桌面完整展示，平板与手机保留左侧图标栏，可展开文字菜单，不改成顶部菜单。

信源采用资讯流与创作定位并列；稿件采用编辑与阅读预览并列；图片采用页面列表、画布、当前页设置三栏；成品采用检查清单与发布记录并列。手机稿件可切换编辑与预览，图片采用横向页面列表。五步进度和平台状态在作品内连续展示。

建议试用：信源转选题 → 开始创作 → 选择平台 → 模拟生成 → 修改确认 → 逐页确认模板 → 人工核对、确认成品 → 下载预览、模拟登记。再试小红书失败与单端重试、已有稿的候选比较、改稿后图片待更新、发布快照。

“外观设置”提供森林编辑室、雾蓝工作室、奶油暖光、樱粉手帐、深夜墨黑五套主题。选择即预览，“保存外观”后跨页和刷新恢复；“放弃预览”恢复已保存设置，未保存离开不改变其他页面。主题不改变文章、图片模板的成品配色。

壁纸可上传 5 MB 内 PNG／JPEG／WebP，调整位置、遮罩和临时关闭。“恢复默认”确认后恢复森林主题并清除壁纸，不删除创作内容。可使用自己合法持有的迪丽热巴或奶龙图片，不自带肖像或角色素材。

RedFox 建议试用：原工具切换平台热榜 → 打开详情 → 查看互动指标、收藏 → 追踪作者 → 同步示例作品；搜索选择平台和条数 → 查询 → 历史再次查询、绕过缓存；原工具创作／改写／检测／热点关联／封面 → 确认模拟调用 → 查看结果与日志；素材再转为选题进入新主线。

## 边界

- 来源、稿件与任务都是模拟，不调用 RedFox、模型，不发布或写 OB。
- 图片是模板预览，不是 Codex 生图；只导出演示 HTML，不是真实 PNG 成品包。
- 日期控件用于交互评审，仅固定 2026-10 月历。
- 浏览器只保存独立演示存档，不读取正式数据；清理浏览器会丢失。容量不足显示保存失败和备份入口。
- 壁纸留在浏览器，不发送模型，不随仓库上传，不进入成品。
- RedFox 页面依据现有代码补充主要交互，不是一比一复刻，也没有接入真实接口。评论数量保留，评论全文未找到 RedFox 实现，不能冒称已接通。
- 账号评分与趋势、通知配置、真实封面图只模拟或说明能力边界；动态 Skill 绑定榜单、完整原知识库与真实任务执行尚未细化。正式能力不删除。
- 本轮完成独立原型的布局与视觉评审，不是正式系统美化或部署；现有未发布候选未纳入提交。
- 图片排序／拆页、逐句审稿、真实 OB 搜索／导入、PNG 打包和 Skill 更新仍在 PRD 中，本轮未模拟。

原型验收见 [验收记录](../../交互原型验收-2026-10-12.md) 和 [设计评审](../../原型设计评审-2026-10-12.md)。原型通过不证明正式服务或平台成品可用。
