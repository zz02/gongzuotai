2026-10-12。对应 [PRD 1.4](../../PRD-点灯自媒体工作台.md) 和 [代码盘点](../../代码功能盘点-2026-10-12.md)。

打开 `index.html`，或通过本机静态服务查看。组件随目录携带，无需联网；其他模板是母版参考，不是产品入口。

本机预览：[打开模拟原型](http://127.0.0.1:8098/index.html#sources)。此地址需本机预览服务运行；服务关闭时仍可直接打开目录中的 `index.html`，不需要登录。

## 页面设计

默认深绿左侧导航、暖白创作区和统一控件。菜单分为创作工作区、创作辅助、RedFox 工具区；桌面完整展示，平板与手机保留左侧图标栏，可展开文字菜单，不改成顶部菜单。

信源采用资讯流与创作定位并列；稿件采用编辑与阅读预览并列；图片采用页面列表、画布、当前页设置三栏；成品采用检查清单与发布记录并列。手机稿件可切换编辑与预览，图片采用横向页面列表。五步进度和平台状态在作品内连续展示。

建议试用：信源转选题 → 开始创作 → 选择平台 → 模拟生成 → 修改确认 → 逐页确认模板 → 人工核对、确认成品 → 下载预览、模拟登记。再试小红书失败与单端重试、已有稿的候选比较、改稿后图片待更新、发布快照。

“外观设置”提供森林编辑室、雾蓝工作室、奶油暖光、樱粉手帐、深夜墨黑五套主题。选择即预览，“保存外观”后跨页和刷新恢复；“放弃预览”恢复已保存设置，未保存离开不改变其他页面。主题不改变文章、图片模板的成品配色。

壁纸可上传 5 MB 内 PNG／JPEG／WebP，调整位置、遮罩和临时关闭。“恢复默认”确认后恢复森林主题并清除壁纸，不删除创作内容。可使用自己合法持有的迪丽热巴或奶龙图片，不自带肖像或角色素材。

RedFox 建议试用：原工具切换平台热榜 → 打开详情 → 查看互动指标、收藏 → 追踪作者 → 同步示例作品；搜索选择平台和条数 → 查询 → 历史再次查询、绕过缓存；原工具创作／改写／检测／热点关联／封面 → 确认模拟调用 → 查看结果与日志；素材再转为选题进入新主线。

## 边界

- 来源、稿件与任务都是模拟，不调用 RedFox、模型，不发布或写 OB。
- 图片是模板预览，不是 Codex 生图；只导出演示 HTML，不是真实 PNG 成品包。
- 日期控件用于交互评审，仅固定 2026-10 月历。
- 浏览器只保存独立演示存档，不读取正式数据；清理浏览器会丢失。容量不足显示保存失败和备份入口。
- 壁纸留在浏览器，不发送模型，不随仓库上传，不进入成品。
- RedFox 页面依据现有代码补充主要交互，不是一比一复刻，也没有接入真实接口。评论数量保留，评论全文未找到 RedFox 实现，不能冒称已接通。
- 账号评分与趋势、通知配置、真实封面图只模拟或说明能力边界；动态 Skill 绑定榜单、完整原知识库与真实任务执行尚未细化。正式能力不删除。
- 本轮完成独立原型的布局与视觉评审，不是正式系统美化或部署；现有未发布候选未纳入提交。
- 图片排序／拆页、逐句审稿、真实 OB 搜索／导入、PNG 打包和 Skill 更新仍在 PRD 中，本轮未模拟。

原型验收见 [验收记录](../../交互原型验收-2026-10-12.md) 和 [设计评审](../../原型设计评审-2026-10-12.md)。原型通过不证明正式服务或平台成品可用。

本机验收脚本 `verify-design.cjs` 使用仓库已有 Playwright 与 macOS Chrome，检查新版交互、键盘与实际分栏；`capture-design.cjs` 通过真实点击生成隔离示例截图。静态预览入口不依赖这些测试组件。`verify.cjs` 保留为上一轮布局的历史基线，不是新版验收入口。

补充验收：`verify-redfox-themes.cjs` 检查 RedFox 主路径及五套主题；`verify-redfox-recovery.cjs` 检查独立审查发现的筛选、缓存、创作、追踪与损坏存档问题；`capture-redfox-themes.cjs` 生成真实浏览器截图。旧测试未修改。见 [RedFox 与主题评审](../../原型评审-RedFox与主题-2026-10-12.md)。
