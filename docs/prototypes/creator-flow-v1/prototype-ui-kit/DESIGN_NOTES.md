# 设计来源说明

本组件库用于纯 HTML 原型，不直接依赖 Ant Design、Element Plus、Arco Design、TDesign 的运行时。

视觉参考来源以 `component-library-free-downloads/package.json` 中本机实际安装版本为准：

- TDesign：品牌蓝、文本层级、页面背景、状态色、后台密度。
- Ant Design：按钮、表格、弹窗、表单的 B 端交互模式。
- Arco Design：清爽的中性色、填充色、4px/8px 圆角体系。
- Element Plus：Vue 后台常见表单和表格密度。
- Ant Design Mobile / Vant / TDesign Mobile / NutUI / Ionic / Arco Mobile：移动端列表、顶部栏、选择器、动作面板、键盘和业务组件结构。

落地原则：

1. 只吸收设计语言，不复制框架类名。
2. 统一使用 `pui-` 前缀，避免污染业务项目。
3. 适配纯 HTML 文件，可直接双击打开。
4. 优先服务原型表达，不替代真实前端组件库。
5. 控件高度、圆角、状态色、表格密度保持跨项目一致。

当前视觉基准：

- 主色：接近 TDesign 品牌蓝 `#0052d9`。
- 控件高度：默认 `32px`，大尺寸 `40px`。
- 圆角：常规 `4px`，容器 `6px`。
- 页面背景：冷静浅灰，适合政务/B 端后台。
- 表格：固定表头底色、44px 行高、操作列右对齐。
- 弹窗：居中遮罩、52px 标题栏、底部按钮右对齐。

设计令牌采用三层结构：

1. 基础令牌定义原始颜色、字号、间距、圆角、阴影和动效时长。
2. 语义令牌定义页面、表面、文本、边框、主色和状态色。
3. 组件令牌定义按钮、输入框、表格、面板、导航和遮罩的实际使用值。

页面模板采用同一布局节奏：顶部栏 58px、内容间距 20px、面板标题栏 48px、默认表格行 44px、桌面控件 32px、移动端触控控件不低于 44px。

不建议：

- 不要在同一个项目里混用多个组件库视觉。
- 不要把业务字段名写进组件库。
- 不要在原型里出现多个不同样式的日期选择器。
- 不要把按钮文案写成长句。
