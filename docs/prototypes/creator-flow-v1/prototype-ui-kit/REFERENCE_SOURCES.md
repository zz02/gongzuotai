## 归并规则

1. React / Vue 同名控件只映射一次 PUI 能力。
2. `ConfigProvider`、`Portal`、`Trigger`、`FocusTrap`、`VirtualList`、`Router` 等运行时能力不创建无界面的假组件。
3. Card 子件、TableColumn、TabPane 等组合子件归入父组件规格。
4. 电商和媒体专用能力在 `examples/specialized.html` 展示。
5. 日期时间家族不归并成一个“日期框”，分别保留日期、时间、范围和日期时间组合。
