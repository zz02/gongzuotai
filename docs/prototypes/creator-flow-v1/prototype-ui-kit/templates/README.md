# 页面模板

这里提供七类可直接使用的业务页面。模板使用真实业务文案、完整状态和闭环交互，可作为新项目入口，也可复制局部结构。

| 模板 | 文件 | 主要能力 |
|---|---|---|
| 列表页 | `list-page.html` | 概览、筛选、批量操作、表格、分页、新建弹窗 |
| 详情页 | `detail-page.html` | 对象头部、描述信息、Tab、时间线、进度、转派抽屉 |
| 编辑页 | `edit-page.html` | 分组表单、错误提示、上传、草稿、提交校验 |
| 审批页 | `approval-page.html` | 审批步骤、申请材料、审批记录、决策确认 |
| 看板页 | `dashboard-page.html` | 指标、趋势图、排行、分类分析、运营提醒 |
| 配置页 | `config-page.html` | 分类配置、开关、输入组合、权限表格、新增角色 |
| 移动端列表页 | `mobile-list-page.html` | 搜索、状态筛选、业务卡片、筛选抽屉、底部导航 |

模板目录内引用 `../dist/prototype-ui.js`，可以直接双击打开。通过 `create-project.sh` 创建项目后，路径会自动改为项目内组件库路径。

模板只负责页面结构和示例业务内容。按钮、输入框、表格、弹层、间距和响应式规则仍由 `dist/prototype-ui.css` 统一控制。
