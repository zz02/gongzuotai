# 点灯工作台：功能原型验收

日期：2026-10-12。对应 PRD 1.3。最新结论：左侧导航新版原型 21 组检查通过，独立原型布局与视觉评审完成；正式系统功能与 UI 尚未按新版改造。第 1～4 节保留上一轮记录，第 5 节为最新补充。

## 1. 执行范围

使用本机 Chrome 实际打开独立原型，自动检查交互并检查渲染截图。14 组结果通过；九个视图分别检查 1440、768、375 三种宽度。仅模拟存档，未调用正式接口、RedFox、模型、发布和真实 OB。

同时检查四份文档无失效本地链接；Chrome 直接打开本地文件可显示三个信源且无脚本错误。随附组件样式和脚本已显式纳入版本管理，避免仓库默认忽略编译目录导致下载后页面缺样式。

| 检查 | 实际结果 |
|---|---|
| 三信源、选题立项、空平台 | 三分组可见；无平台阻止立项；建立不触发生成 |
| 双端部分失败与重试 | 公众号成功端保留；小红书单端重试完成 |
| 保存与刷新恢复 | 手改标题刷新仍在同一作品 |
| 生成期间手改 | 候选保留，直接覆盖被禁止 |
| 局部采用 | 只采用标题，不改变当前正文 |
| 单页恢复与成品检查 | 当前页失败可重试；缺清单不得下载成品预览 |
| 发布登记与版本 | 缺证据拦截；时间选择有效；备注登记与快照保留；后改使旧图待更新 |
| 重复来源 | 回已有选题，不新建第二个作品 |
| 壁纸 | 损坏图片拒绝；有效图片可上传、保存和刷新恢复 |
| 三屏宽 | 九个视图无页面横向溢出；窄屏主导航仍可用 |
| 外观恢复 | 清除壁纸不删除作品 |
| 存储容量异常 | 显示失败、保留当前编辑、提供备份，不假报保存 |
| 损坏存档 | 后续写入前保存原始演示存档备份 |
| 脚本与网络 | 无未捕获错误；无外部请求 |

复查修正了窄屏侧栏大空白、日期弹层裁切、忙碌壁纸干扰标题和左右编辑面板对齐；图像变更也会撤销人工核对。截图是最终原型，不是正式内容产物。

## 3. 未验收与风险

1. 不证明当前正式系统、登录、模型或三信源运行可用，也不是历史超时根因结论。
2. 不生成真实图片或完整 PNG 包，HTML 模拟预览不能直接视为平台成品。
3. 未测试平台后台粘贴、真实发布、真实 OB 读写、Skill 更新及图片排序／拆页。
4. 壁纸不自带迪丽热巴或奶龙素材，个人文件不会随 GitHub 提交；浏览器容量及清理可能影响演示存档。
5. 本机预览服务不是常驻生产部署；关闭后可从本地原型文件重新打开。

## 4. 交付自查

代码证据、目标需求和模拟页面已分层；三信源与 RedFox 保护有唯一落点；五步操作和作品内三段制作一致；未发布候选未部署或提交。下一阶段依据用户评审意见改造正式工作台，再验证真实素材、模型产物、平台成品与 UI。

## 5. 左侧导航与视觉复验

使用新脚本 `verify-design.cjs` 在本机 Chrome 实际检查，21 组通过；上一轮 `verify.cjs` 未修改，保留为历史布局基线。

保留三信源、立项、部分失败与单端重试、手改保护、候选比较、逐页恢复、成品检查、登记快照、壁纸和存储异常的检查；新增左侧菜单的实际位置、抽屉键盘循环、关闭与焦点恢复、手机编辑／预览切换、桌面双栏与三栏实际位置、普通弹窗背景隔离、当前导航语义和登记后修订提示。九个视图在 1440、768、375 三种宽度无页面横向溢出；本地文件离线入口可显示三信源。

视觉复查发现清理旧样式时曾丢失两处网格布局，已撤销该次变更，重新整理后补实际栏位位置断言；最终截图和测试基于修正后的版本。不能用“无溢出”替代“布局正确”。

新版设计与截图见 [设计评审](原型设计评审-2026-10-12.md)。独立复核指出的弹窗背景、当前页语义和成品主按钮问题已修正。未执行跨模型外部复核，也未声称完整无障碍合规、跨浏览器兼容或真实性能评测通过。

## 6. RedFox 与主题补充复验

主要 RedFox 操作由说明页改为可点击的热榜、搜索、详情、追踪、原创作、收藏、运行设置；外观增加五种完整主题。原有 21 组回归通过，新增路径与 120 种主题／页面／屏宽组合通过；独立审查发现的筛选回显、缓存误标、创作模式遗漏、追踪分组和损坏存档问题已修正并补充复验。

需求、截图、脚本和未覆盖边界见 [RedFox 与主题评审](原型评审-RedFox与主题-2026-10-12.md)，不重复作为另一份需求规则。
