# 点灯自媒体工作台：代码功能盘点

> 使用边界：保留本文的历史代码事实和定位证据；其中五步流转、统一选题卡和保留重复导航等设计建议已被替代。当前功能归属与交互以[本轮评审方案](功能归属与关键交互-点灯工作台-2026-10-13.md)为准。代码事实不等于当前运行验收。

日期：2026-10-12。基准：主分支提交 `9ee9530`。本次为代码审计，不调用收费信源、不发布作品、不修改正式页面。

结论：不是缺少所有创作能力，而是已有能力分散在原工具、文件项目和新工作台，入口、作品关系与完成标准不一致。应沿用已有能力，先补齐一条创作业务流程，再做美化。源码存在、曾经验证、当次可用、用户认可是四种不同证据。

## 1. 现有功能与处理建议

| 功能 | 代码实际行为 | 依赖与边界 | 本次设计处理 |
|---|---|---|---|
| 原热榜 | 平台热榜、关键词趋势、同步及定时获取 | RedFox 凭证、所配平台与调用规则 | 全部保留，不更改入口、筛选与历史 |
| 原搜索与详情 | 抖音、小红书、公众号查询；详情显示原链接、互动统计、收藏与创作入口 | 搜索缓存；平台返回内容有差异 | 保留；只增加选中材料进入新选题的桥接 |
| 评论信息 | 所检查详情页显示评论数量；另有小红书 MCP 相关能力 | 不能据此声称已有 RedFox 评论全文获取 | 现有展示和功能不动；全文能力以实际页面与接口验证为准 |
| 原 AI 创作 | 创建、改写、风格、热点关联、检测、封面等 | 配置模型与 RedFox 是不同依赖；部分调用需确认 | 原流程保留，新增 Skill 审稿不替换检测 |
| AI 资讯 | AIHOT、乔木若干频道、辅助官方频道；查询、分页、缓存、独立失败提示 | 固定地址、大小和超时限制；不是任意订阅管理器 | 前两者作为独立主分组，官方频道辅助保留 |
| 灵感库 | 手工选题、配置来源、生成、状态、反馈、收藏、回收站 | 独立灵感记录 | 保留历史；新增选题视图需要统一关联关系 |
| 资讯转选题 | 实际直接创建／复用工作台作品，携带摘要及待核验说明 | 没有写入原灵感列表 | 先进入统一选题卡，开始创作后关联唯一作品 |
| 原文件项目 | Markdown 工作空间、来源灵感、Skill 执行与采用 | 与新工作台不是同一正文存储 | 继续可查；导入先预览，不按标题强制合并 |
| 新工作台 | 作品保存在本地数据库，任务与图片另有文件；每次保存检查版本 | 独立作品和来源关联，重复转入不覆盖原稿 | 作为新增创作主线的正文主系统 |
| 多平台稿 | 有公众号、小红书和抖音图文标题、正文、摘要／配文；有初稿任务及候选采用 | 本机 Codex、登录与网络；只写题目可能缺事实 | 本平台直接显示结果；区分准备稿与待确认稿 |
| 候选保护 | 原稿版本变化时阻止整篇覆盖，导入也先形成候选 | 当前冲突后主要靠复制与手合并 | 补标题／正文分别采用、当前稿与候选并看 |
| 任务执行 | 写作、生图、本地卡片；全局单任务占用；任务失败保留错误 | 写作上限 4 分钟、生图 10 分钟；没有已证实的取消机制 | 真实状态、单端重试、刷新恢复；不画假百分比和假取消 |
| Skill 中心 | 原来源、社区与命令管理，新增创作方法适配和回工作台入口 | 文件存在不等于执行过；有许可及模型条件 | 来源／适配／验证／执行环境分别标注 |
| 原生生图 | 通过本机 Codex 调用内置生图，检查图片和执行证据；小红书先封面后内页 | 网页不能直接持有本聊天工具；模型图片中文字不是可编辑文字层 | 保留；补用途、逐页状态、局部更新和失败恢复 |
| 模板图卡 | 本地文字卡片，支持小红书及抖音逐页内容 | 非 AI 生图；当前不是完整截图混排编辑器 | 标明制作方式；补截图导入、排序与逐页预览 |
| 公众号排版 | 本地正文预览、复制富文本、HTML 下载 | 标题后台另填；粘贴、外部图片需人工核对 | 标题摘要封面与正文在同一成品预览 |
| 成品检查 | 查标题、正文、摘要／配文；小红书／抖音查当前稿匹配图片 | 公众号没有封面必需检查；事实与人工检查未统一 | 补可解释的必需清单，不把字段齐全当可发布 |
| 成品导出 | 当前主要导出嵌入图片的 HTML | 不是独立 PNG＋原稿＋清单的完整打包；有大小限制 | 目标补整套有序图片、原文、排版和发布指引 |
| 发布登记 | 平台、有效链接、北京时间；重复链接阻止登记 | 仅登记，并不自动发布；未冻结完整成品快照 | 导出不算发布；新增待核对备注及版本快照 |
| 发布复盘 | 人工填阅读、点赞、收藏、关注与备注；空值不当零 | 当前没有完整观察时间与评论复盘结构 | 补观察口径，不推算无归因的涨粉 |
| 工作台 OB | 可读目录内选笔记、预览引用、候选导入、图片与独立归档快照 | 文件名／目录搜索，不是语义搜索；不改源笔记 | 素材就近选入，归档就近操作，原文与快照分开 |
| 原知识库 | 收藏、OB／Notion／RSS 接入、分析、匹配、创建与保存等 | 原模块部分操作可写入，并非全部只读 | 原能力保留；不能用新工作台只读规则描述整个旧模块 |
| 视频 | 本地录屏文件、讲解音频、字幕与 FFmpeg 合成 | 不是完整录像／剪辑器，受本机依赖限制 | 现有入口保留，本轮不扩建 |
| 外观 | 只有明暗主题与系统跟随 | 当前没有用户壁纸模块 | 新增个人外观设置，不更改发布素材 |
| 我的账号与风格 | 账号记录、赛道提取、风格档案、预设灵感与提示词模板 | 旧账号档案不同于新工作台创作档案 | 保留，后续明确如何采用，不自动覆盖个人定位 |
| 账号追踪 | 同步作品、缓存诊断、账号趋势和快照 | 可刷新，不等于平台账号发布权限；数据新鲜度单独提示 | 原能力保留，参考观察不冒充本人作品涨粉归因 |
| 定时与通知 | 热点、追踪、RSS 等定时任务、立即运行、任务排序及通知 | 有固定保护任务，灵感调度单独管理 | 保留原调度，不因新主线擅自停用或增加调用 |
| Agent 对话 | 代理列表与聊天入口 | 与受控的平台稿件任务不同 | 辅助入口保留，不另存一套“正式正文” |
| 登录与设置 | 首次初始化、登录限流、会话、账号资料、改密码与依赖设置 | 本机账户不是 ChatGPT 账户；初始化不可重复覆盖 | 不改凭据和账户，异常反馈与创作恢复另验 |
| 备份与诊断 | 备份列表、创建、校验；只读系统诊断 | 所查接口不是完整自动恢复流程；附件范围需核对 | 保留，正式迁移前另做可恢复性验证 |
| 运营目标 | 创作档案、时间预算、粉丝基线及目标、人工更新总粉丝 | 当前不是三个平台独立日期快照的完整指标模型 | 退到运营辅助区域，不占稿件操作首屏 |

## 2. 五步业务流程的断点

| 断点 | 用户受到的影响 | 需求设计与验收 |
|---|---|---|
| 不同来源转入不同对象 | “转选题”后不知道去哪个列表找 | 三主信源使用同一选题卡；重复转入回原卡和作品 |
| 一页混合稿件、助手、素材、任务和复盘 | 用户看到任务却找不到公众号／小红书正文 | 作品内三段制作；平台结果和失败留在本平台 |
| 当前转入灵感可能自动生成 | 未确认素材与范围就等待长任务 | 转入不执行；生成前显示平台、素材、缺口与依赖 |
| 单任务占用但像全平台同时工作 | 不清楚是在排队、失败还是没有结果 | 平台分别标等待、生成、成功、失败，只重试失败端 |
| 候选和正文的位置分离 | 成功但还需找到采用按钮 | 空稿显示待确认初稿；已有稿显示对比，不覆盖 |
| 字段检查被当成成品检查 | 公众号缺封面也可能看似齐全 | 本人核对＋封面／页数＋当前版本匹配必须通过 |
| HTML 文件被称成品包 | 还得手工找图、排序、复制原稿 | 显示真实清单；完整文件实际打开后才算交付 |
| 发布后没有明确冻结稿 | 修改现稿后难以还原已发布版本 | 登记保留快照，后改成为修订稿 |

这些是产品与实现差距，不是某个历史任务超时的根因报告。不能从静态代码断言本机服务、外部接口或每次模型执行都可用。

## 3. 保留、复用、新增、后置

- 保留：所有原 RedFox 热点、搜索、评论信息、检测、封面及相关原入口；原配置、缓存、日志、调用确认不变。
- 复用：来源缓存、作品数据库与版本保护、平台初稿任务、固定方法适配、原生图片任务、模板渲染、公众号排版、OB 范围控制和独立快照。
- 新增：统一选题关系、作品内步骤导航、平台就近反馈、候选比较、逐页图片管理、完整成品清单与快照、个人壁纸。
- 后置：视频扩建、真实自动发布、全库语义检索、实时双向同步、自动学习个人表达和增长预测。
